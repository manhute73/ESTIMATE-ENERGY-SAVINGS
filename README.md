# VOX Cool: Cold Storage Energy Savings Estimator

Static site (HTML/CSS/JS). No build step.

- `calc.js`: placeholder formula. Replace it with the real one.
- `app.js`: screens, validation, state electricity rates (placeholder values).
- `styles.css`: layout and theme.

## Run locally
Open `index.html`, or run `npx serve .`

## Deploy
Push to GitHub, then in Vercel choose **Add New > Project**, import the repo, keep the defaults (Framework: Other, no build command, output directory empty) and click Deploy.
